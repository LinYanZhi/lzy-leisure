# lzy-leisure 视频模块交互重构设计草案（移动优先）

> 状态：草案（待调研结果合并）
> 目标：手机上看视频达到主流视频 App 的顺手程度；PC/网页/手机三端统一。

---

## 一、核心问题诊断（现状）

1. **点视频不直接播放**：手机端无 hover 播放键，点卡片进详情页，再点播放按钮 → 两步才能看，反直觉。
2. **播放器移动体验差**：依赖原生 `controls`；无手势（点/滑/双击）；控制栏不自动隐藏；进入不全屏；无屏幕常亮。
3. **详情页是编辑表单**：手机端打开就是一堆输入框，浏览意图和编辑意图混在一起。
4. **无"继续观看"**：有进度记忆但书架上没有入口。
5. **返回栈/手势**：系统返回键、边缘滑动返回没有处理，播放器返回经常"一步到位"退回书架。
6. **移动导航**：顶部二级导航 + 抽屉，信息层级可优化。

## 二、设计原则

- **点即播（Play-first）**：浏览视频的默认动作 = 播放，不是看详情。
- **剧集优先详情**：只有"多集聚合"（剧集/系列）点开才进详情/集列表；单集视频点开即播。
- **编辑与浏览分离**：元数据编辑收进独立"编辑"入口，浏览页保持干净。
- **手势优先（移动）**：播放器用点击/滑动/双击控制，不依赖小按钮。
- **返回栈真实**：播放 → 详情 → 列表，系统返回/手势逐级回退。
- **继续观看**：书架顶部常驻"继续观看"横排。

## 三、分层设计

### 3.1 书架 / 列表（移动端）
- 网格卡片（2 列），卡片=封面+标题+时长+进度条。
- **单击卡片**：
  - 单集视频（无 series_id）→ **直接进入播放器**。
  - 剧集/系列 → 进入剧集页（集列表）。
  - 短视频（short kind）→ 直接播放（竖屏沉浸）。
- **长按卡片** → 底部操作菜单（详情 / 播放 / 删除 / 打开目录 / 标记）。
- **"继续观看"横向行**：有 progress 的视频，显示进度，点即续播。
- **分类筛选**：横向 chips（电影/电视剧/短视频/AV/动漫/竖屏）+ 搜索 + 演员/标签筛选（保留）。
- 桌面端：保留侧边栏 + 网格；卡片单击同样"点即播"，hover 保留快捷播放/更多按钮。

### 3.2 视频详情（移动端改为"浏览+编辑两态"）
- 浏览态（默认）：大封面、标题、车牌、演员 chips（点演员→演员页）、标签、简介、时长/分辨率、所属剧集（可切集）、"继续观看/从头播放"按钮、相关同演员视频。
- 编辑态：原编辑表单（标题/简介/车牌/年份/评分/种类/演员/标签/封面），右上角"编辑"进入。
- 桌面端：详情页可左右分栏（浏览+编辑），或保留现状但把"播放"按钮置顶。

### 3.3 播放器（移动端重构，核心）
- **进入即全屏**：移动端进入播放器自动 requestFullscreen（横屏/竖屏自适应）。
- **手势**：
  - 单击屏幕：播放/暂停。
  - 双击屏幕左侧 1/3、右侧 1/3：后退/快进 10s（双击中间=播放暂停）。
  - 水平滑动（播放中）：快速 seek（配合进度提示）。
  - 垂直滑动屏幕左侧/右侧：亮度/音量（可选，web 端系统层面受限时可只做音量）。
  - 上滑退出全屏 / 下滑退出播放器（可选）。
- **控制栏**：
  - 顶部：返回（退出播放器，回详情/列表）、标题、倍速、字幕开关。
  - 底部：进度条（可拖）、当前/总时间、上一集/下一集、全屏/退出全屏。
  - **3 秒无操作自动隐藏**；点击唤出。
- **屏幕常亮**：播放时 navigator.wakeLock.request("screen")。
- **连播**：剧集播完自动下一集 + 顶部提示；单集播完停留 + 显示"重播/下一个相关"。
- **续播**：已有逻辑保留（进入跳进度 + 每 5s 保存）。
- **格式警告**：保留 mkv/avi 等手机浏览器兼容警告。
- **竖屏模式**：视频顶部显示，控制栏在下；非全屏时保留。

### 3.4 移动导航
- 视频模块内：**底部二级 tab**（首页/全部 / 剧集 / 演员 / 标签 / 我的?）或保留顶部横向二级导航但精简。
- 模块切换（漫画/视频/小说/故事会）保留现有底部模块导航。
- 演员页：点击演员 → 演员详情（头像+档案+TA 的影片，点即播）。
- 抽屉（完整导航：种类/导入路径/管理）保留但作为次要入口。

### 3.5 返回栈
- App 内维护视频模块视图栈：shelf → detail → actor → series → player。
- 播放器返回：回到进入前的视图（详情/列表），不是直接回书架。
- 监听浏览器/系统返回（popstate）逐级回退；移动端边缘滑动返回适配。
- 桌面 Esc 逐级回退。

## 五、调研结论（已合并，详见《移动端视频应用交互设计调研报告》）

1. **点卡片 vs 进详情 → 按内容类型分档**（不是二选一）：
   - **AV / 短视频 → 点封面即播**（决策成本≈0，本项目主力内容）；详情降为次要路径（"⋯"菜单进入）
   - **电影 / 剧集 → 详情优先**（主按钮三态：播放 / 从上次继续 / 重播）；剧集=季-集两级
2. **手势（播放器）**：双击左/右 1/3 = ±10s（带 toast）；单击中央=播放暂停；上下滑=切下一个（列表上下文内，P1）；控制栏 3s 自动隐藏；单击唤出。
3. **导航**：媒体库 App 用底部 Tab；本项目因 app 级底部已有「漫画/视频/小说/故事会」模块导航，视频模块内二级导航用**顶部横滑 chips**（分类 1 键直达，AV 也在此）。
4. **竖屏/横屏**：浏览锁竖屏（不随传感器旋转）；播放器横竖都支持；移动端进入播放器**自动全屏**（作用于整个播放器含顶栏）。
5. **返回栈红线**：**返回不杀播放**。全屏播放=模态层：返回先退全屏（播放不中断）→ 收缩 mini player → 逐级退，状态保留。播放器内提供显式"关闭"。
6. **续播**：进度存自建后端、三端同步、详情主按钮三态、继续观看行。
7. **AV 特化**：高密度封面网格、点即播、无痕模式/应用锁（P1，隐私前置）。
